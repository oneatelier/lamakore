# Trademark Policy

The name "Lamakore" is the confirmed product name, and this policy
follows the mark: the code is Apache-2.0, the name and marks are not.
No license to use them is granted by the code license (see LICENSE §6,
which withholds trademark rights).

House rule: use ™ (unregistered claim of use) where the mark is
asserted, never ® before an actual registration. No registration
exists; filing is deferred to entity formation.

## What this means

- The code is Apache-2.0. The **name and marks are not**: no license to
  use them is granted by the code license (see LICENSE §6, which
  withholds trademark rights).
- You may make nominative, factual references ("compatible with",
  "based on Lamakore") where truthful and non-confusing.
- You may NOT present a fork, distribution, hosted service, or commercial
  product as Lamakore, use confusingly similar names or logos, or
  imply endorsement, without prior written permission from the Maintainer
  of Record.
- Community ports and builds must be clearly renamed or carry a
  prominent disclaimer of unofficial status on every download page.

## Model

This policy is modeled on the Apache Software Foundation and PostgreSQL
approach: permissive code, protective marks, permission available for
legitimate community uses on request. Permission requests go through the
same private channel as security reports until a dedicated marks address
is published in an ADR.
